04 - HTML

Every Page Starts the Same Way

<!DOCTYPE html>
<html>

<head>
  <title>My Page</title>
</head>

<body>

  <h1>Hello!</h1>

</body>

</html>

head

Information about the page. None of it shows up on screen. The title is the browser tab.

body

The page itself. Everything a visitor sees goes in here.

Type this once and you have a working web page. Everything from here goes inside <body>.
