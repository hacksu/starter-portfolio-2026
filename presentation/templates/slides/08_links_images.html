07 - HTML

Links and Images

a - a link

<a href="https://hacksu.com">
  HacKSU
</a>

<a href="about.html">About me</a>

<a href="mailto:me@example.com">
  Email me
</a>

href is where it goes. The text between the tags is what you click.

img - an image

<img src="photo.jpg"
     alt="A photo of me">

src is which file. alt describes it.

No closing tag. There is nothing to wrap around, so it stands alone.

alt is not optional. It is what a blind visitor's screen reader says out loud, and what shows if the image fails to load.
