08 - CSS

A Bit of CSS

h1 {
  color: darkgreen;
  font-size: 3rem;
}

p {
  color: #333;
  line-height: 1.6;
}

img {
  width: 200px;
}

Pick something, change it

The name in front is what to find. Inside the braces is what to change.

Connect it to your page

<head>
  <link rel="stylesheet"
        href="style.css">
</head>
Worth knowing today: color, background, font-size, padding, margin, width. That is enough to make a page yours.
