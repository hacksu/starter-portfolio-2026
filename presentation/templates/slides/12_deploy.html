11 - Deployment

Putting It on the Internet

Vercel - drag the folder in

  • Go to vercel.com/new
  • Drag your folder onto the page
  • Change nothing
  • Deploy
→ your-project.vercel.app

No terminal. No Git. No build step. Drag, drop, live.

GitHub Pages

  • Put the folder in a GitHub repo
  • Settings → Pages
  • Branch main, folder / (root)
  • Save, wait a minute
→ yourname.github.io/repo/

Slower to start, but free forever and it lives next to your code.

Your page is plain files, so hosting it costs nothing. That is the payoff for not using a framework.
