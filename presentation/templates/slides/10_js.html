09 - JavaScript

A Bit of JavaScript

<h1 id="title">Hello</h1>
<button id="go">Click me</button>

<script>

  const title = document.getElementById("title");
  const go    = document.getElementById("go");

  go.addEventListener("click", function () {
    title.textContent = "You clicked it!";
  });

</script>

1. Find something

getElementById grabs a tag by its id.

2. Change it

textContent replaces the words inside it.

3. React to a click

addEventListener runs your code when something happens.

Find something, change it, react to the user. That is most of what JavaScript does on a website.
