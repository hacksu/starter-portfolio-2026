02 - What a Page Is

A Web Page Is Just a File

index.html | | you open it v +----------------+ | browser | | reads it top | | to bottom | +----------------+ | v a web page

A file called index.html, full of text you wrote.

Double-click it and your browser shows a website. No server. No internet.

That is the whole trick. Everything else today is detail.

index.html is the special name. It is the page you get when nobody asks for a specific file.
